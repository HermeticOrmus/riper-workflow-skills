# Using this repo with Cursor

This project includes a Cursor project rule for the RIPER workflow.

## In this repository

1. Open the folder in Cursor.
2. The rule [`.cursor/rules/riper-workflow.mdc`](.cursor/rules/riper-workflow.mdc) is committed with `alwaysApply: false` (invoke when needed).
3. Confirm under **Settings → Rules**.

## Use the same workflow elsewhere

**Cursor**: Copy `.cursor/rules/riper-workflow.mdc` into that project's `.cursor/rules/`.

**Other AI tools**: Copy [`CLAUDE.md`](CLAUDE.md) to the project root.
